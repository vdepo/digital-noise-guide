# Тише в цифре

Сайт-памятка о цифровом шуме для школьного индивидуального проекта «Влияние цифрового шума на психическое состояние здоровья человека». Помогает заметить лишние сигналы и выбрать небольшие настройки цифровой среды.

- Сайт: https://vdepo.github.io/digital-noise-guide/
- Репозиторий: https://github.com/vdepo/digital-noise-guide

## Что на сайте

- Рабочее определение цифрового шума (не медицинский термин).
- Возможные проявления: это наблюдения, а не тест и не диагностика.
- Шесть практических советов и интерактивный мини-план.
- Видео «Цифровой шум за 20 секунд»: без звука, запускается только по нажатию.
- Два режима оформления: яркий «шумно» (по умолчанию) и спокойный «Тише». Переключатель меняет палитру, останавливает бегущую строку уведомлений и ролик на главном экране, а беспорядочные точки складываются в спокойные волны.
- Короткий ролик о сайте на главном экране: без звука, звук включается кнопкой; не запускается сам в режиме «Тише» и при системной настройке «Уменьшение движения».
- Мини-план можно скопировать одной кнопкой, чтобы сохранить его в заметках.
- Источники: ВОЗ, APA и научные обзоры.

Сайт не собирает и не отправляет данные: отметки мини-плана и «Режим «Тише»» хранятся только в браузере (`localStorage`). Шрифты лежат в самом репозитории, сторонних запросов нет. Оформление следует системной светлой или тёмной теме.

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся страница: разметка и тексты |
| `assets/style.css` | Оформление, светлая и тёмная темы, мобильная и печатная версии |
| `assets/app.js` | Мини-план, ссылки на источники, подсветка меню, появление блоков (на компьютере), анимация главного экрана |
| `assets/fonts/` | Шрифты Geist и Geist Mono (лицензия SIL OFL) |
| `assets/film.mp4` | Видео «Цифровой шум за 20 секунд» (1920×1080, без звука) |
| `assets/film-poster.jpg` | Обложка видео до запуска |
| `assets/brag.mp4` | Ролик о сайте на главном экране (720×1280, 21 секунда) |
| `assets/brag-mobile.mp4` | Тот же ролик для экранов до 900 px (540×960, легче) |
| `assets/brag-poster.jpg` | Обложка ролика |
| `assets/favicon.svg` | Значок сайта |
| `assets/apple-touch-icon.png` | Значок для экрана «Домой» на iPhone |
| `assets/og.png` | Превью ссылки в мессенджерах (1200×630) |

Сборка не нужна: это статичный сайт без зависимостей.

## Как посмотреть локально

```bash
open index.html
```

## Как обновить сайт

1. Перейдите в папку проекта и подтяните свежую версию:

   ```bash
   cd ~/Documents/digital-noise-guide
   git pull
   ```

2. Внесите правки. Если менялся файл в `assets/` (стили, скрипт, видео, картинка), увеличьте номер версии `?v=N` у ссылки на него в `index.html`, чтобы браузеры не показывали старый кэш.
3. Проверьте страницу (`open index.html`) и отправьте изменения:

   ```bash
   git add -A
   git commit -m "Что изменилось"
   git push
   ```

GitHub Pages автоматически опубликует обновление из ветки `main`, обычно за минуту-две.
